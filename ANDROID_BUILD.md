# Playing on Android

After the Render deployment is live, open its HTTPS address in Chrome on each phone. In Chrome, open the three-dot menu and choose **Add to Home screen** (or **Install app**, if shown). Each player joins the same room code from their own phone.

This package is a mobile-friendly web app/PWA. It does not contain a signed Android APK. A native APK would require a separate Capacitor build and Android signing setup.
